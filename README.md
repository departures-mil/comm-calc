# Comm Calc

İHA alıcı/verici **link bütçesi** hesaplayıcısı: verici gücü, anten kazançları, kablo/konnektör/VSWR kayıpları, serbest uzay kaybı, engel/bitki/yağmur/polarizasyon kayıpları ve alıcı hassasiyetiyle bağlantının çalışıp çalışmadığını ve kalitesini gösterir.

- Açılıp kapanabilen, yeniden adlandırılabilen kazanç/kayıp kalemleri; blok, seviye, menzil ve Fresnel diyagramları
- Çeviriciler: dBm/mW/W, VSWR/geri dönüş kaybı, dB/% kayıp, dBi/dBd, FSPL, kablo, EIRP, Fresnel, radyo ufku…
- Tablolar: VSWR, güç, FSPL, kablo, bantlar, 5,8 GHz FPV kanalları, engel kayıpları
- Anten ansiklopedisi ve ışıma diyagramları, eğitim bölümü
- Cihaz/anten kütüphanesi; görsel veya teknik metinden tanıma (çevrimdışı ayrıştırıcı + Gemini)
- Uygulama içinden tek tıkla güncelleme

**İndir:** [Sürümler](https://github.com/departures-mil/comm-calc/releases/latest) → `Comm-Calc-vX.Y-Tasinabilir.exe` (kurulumsuz) veya `.rar`.
